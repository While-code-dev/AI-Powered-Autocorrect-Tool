# AI-Powered Autocorrect Tool

## Overview

The AI-Powered Autocorrect Tool is a web-based application built using Python and Streamlit that helps users detect and correct spelling mistakes in text. The tool provides instant corrections through a simple and interactive user interface.

## Features

- Corrects spelling mistakes in user-entered text
- Clean and user-friendly interface
- Attractive gradient background design
- Instant text correction
- Clear and reusable text input area
- Built using Python and Streamlit

## Technologies Used

- Python
- Streamlit
- PySpellChecker

## Installation

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Navigate to the project folder:

```bash
cd AI-Powered-Autocorrect-Tool
```

3. Install the required dependencies:

```bash
pip install -r requirements.txt
```

## Running the Application

Run the following command:

```bash
streamlit run app.py
```

The application will open automatically in your default web browser.
